1. Executive Summary & Core Objectives

The AZ-900 Vibe Planner is a purpose-built exam preparation command center designed to eliminate the friction, study burnout, and schedule rigidity commonly experienced by cloud certification candidates. Instead of static checklists or unstructured video courses, the platform uses an intelligent 3-tier micro-learning model combined with a reactive "Life Happens" Re-balancer.

Key Success Metrics & Pillars

  • Syllabus Fidelity: 100% mapped to Microsoft's official AZ-900 exam objectives and domain percentage weights.
  • Bite-Sized Efficiency: Structured daily sessions (15–60 mins) broken into 3 actionable blocks: Read & Watch (15m), Hands-On Sandbox (10m), and Active Recall (5m).
  • Adaptive Workload Management: One-click schedule re-balancing that redistributes missed study sessions across remaining days without moving the candidate's exam deadline.
  • Active Recall Retention: Integrated knowledge check questions with candidate draft inputs, interactive trainer reveals, and core exam takeaways.
  • Zero-Barrier Instant Demonstration: Instant judge demo mode pre-populating a realistic 7-day plan with completed metrics and live progress bars.

3. System Architecture & Tech Stack

The platform is built using a modern full-stack TypeScript architecture optimized for high performance, edge routing, offline fault-tolerance, and AI integration.

Tier Technology Role & Responsibilities
Frontend Framework Next.js 16 (App Router) + React 19 Server components for SEO & static pages; interactive client components for real-time reactivity and local state.
Language TypeScript 5 Strict type definitions across all study plan models, AI generators, API contracts, and user preferences.
Styling & Design System Tailwind CSS v4 + Glassmorphism Deep slate dark dashboard (#0B0F19), Azure Blue accent (#0078D4), backdrop-filter glass panels, custom responsive grids.
Micro-Interactions canvas-confetti + Lucide Icons Multi-burst celebration confetti upon completing study days; full iconography across Azure services.
State & Persistence Local Storage + Supabase Client Dual-layer persistence: immediate client-side offline storage backed by Supabase cloud storage synchronization.
AI Engine Google Gemini SDK (@google/genai) + OpenAI SDK Dynamic plan synthesis, domain-weighted schedule adaptation, and real-time AI Study Buddy tutoring.

Application Navigation Structure

  • / — Executive Command Center (KPIs, days countdown, readiness gauge, feature quick links).

4. Core Feature & Component Specifications

Feature 1: 30-Second Smart Onboarding Wizard Implemented

Component: components/OnboardingWizard.tsx

  • Target Exam Date Picker: Real-time dynamic calculation of "X Days Remaining".
  • Study Capacity Selector: Interactive pill buttons for 15, 30, 45, and 60+ minutes per day with a toggle for "2x time on weekends".
  • Domain Confidence Sliders: 1-to-5 scale range sliders for Cloud Concepts, Architecture & Services (highlighted as high priority), and Management & Governance.
  • AI Synthesis Multi-Step Loader: 4-step progressive animation demonstrating domain analysis and curriculum customization before revealing the roadmap.
  • Instant Judge Demo CTA: One-click load of a pre-populated plan with Day 1 & Day 2 completed for instant showcase.
Feature 2: Executive KPI Header & "Life Happens" Re-balancer Implemented

Component: components/ReadinessHeader.tsx

  • Countdown Card: Prominent numerical countdown to candidate exam date.
  • Weighted Readiness Score (%): Real-time circular SVG gauge applying official domain weights (27.5% + 37.5% + 32.5% + 2.5%).
  • Domain Mastery Progress: 3 distinct progress bars with domain badges and percentage indicators.
  • The "Life Happens" Re-balancer: When triggered, detects missed sessions, smoothly redistributes remaining workload forward, updates card status to rebalanced, and presents an interactive toast.
Feature 3: Micro-Learning Daily Action Cards Implemented

Component: components/DailyTaskCard.tsx

  • Step 1: Read & Watch (15m): Objective statement paired with direct "Search on MS Learn ↗" linking directly to official Microsoft documentation.
  • Step 2: Hands-On Sandbox (10m): Step-by-step portal exercises (e.g. creating NSG rules, comparing VM sizes, configuring resource locks).
  • Step 3: Active Recall Checkpoint (5m): Exam-style question, draft input box with quick save, and a reveal toggle that unveils trainer explanations and key exam takeaways.
  • Card Footer Toggle: "Mark Day Complete ✅" with celebratory multi-burst confetti and automatic recalculation of overall readiness metrics.
